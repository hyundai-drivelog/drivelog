# DRIVELOG 서비스 기획 요약

**운전자에게 남는 드라이브 기록, 도착하면 찍히는 스탬프.** 현재 차량 기본 모드와 선택적 Android 연결을 구분한다. 사용자 반응과 사업 수치는 검증 전 가정이다.

## 1. 문제 가설과 사용자

1차 타깃은 월 1~2회 주말 드라이브를 가는 30~40대 운전자다. 운전자는 사진을 남기기 어렵고 기록 시작을 잊을 수 있다는 가설을 검증한다. 운전자 모두에게 기록이 없다는 사실을 입증한 것은 아니다. 페르소나: 34세 직장인 민지, 가족과 주말 근교 여행을 가며 운전을 맡는다.

목적지를 확인하고 길 안내 및 기록 시작을 누르면 안내와 기록을 시작한다. 주행 중 최소 정보를 보이고 정차 후 저장하면 경로 카드와 방문 스탬프를 남긴다. P 진입만으로 언제나 자동 저장되는 것은 아니다. 내비 종료 조건에서는 정차 후 자동 저장하고 그 외에는 종료 확인에서 저장한다.

## 2. 차량 환경의 가치

- 기어와 CarUxRestrictions로 주행 중 화면을 기록 또는 잠금 안내로 제한한다.
- 목적지 확인과 기록 시작을 연결하고 기본 내비에 검색·안내를 위임한다.
- 감상과 도장 표시는 정차 후로 미룬다.
- 기본 차량 기록은 서버 연결 없이 동작한다. 휴대폰 앱 설치는 기본 기능의 전제가 아니지만 차량 앱 자체 설치는 필요하다.

## 3. 구현 범위와 차별점 가설

| 기능 | 현재 범위 | 검증 한계 |
|---|---|---|
| 검색·기록·복구·카드·내 기록 | 차량 앱 구현 | 실차·기기별 검증 필요 |
| 전국 17지역·56명소 스탬프 | 기록에서 계산 | 마지막 관측 위치 1km 이내 최근접 한 곳. 입장·체류 인증 아님 |
| 스탬프 최소 조건 | 거리 0.1km 이상·위치 두 점 이상, 시뮬레이션 제외 | 주차 위치·GPS 오차 검증 필요 |
| 휴대폰 기록·스탬프 조회 | 별도 Android 앱＋자체 서버 | 실제 폰·HTTPS·사진 내보내기 검증 필요 |
| 커뮤니티·추천 코스 | debug 목업 | 운영 공유 서비스 아님 |
| 과거 QR 웹 | 삭제됨 | 기본 제출 빌드에서 비활성. 친구 유입 구현 실적으로 사용하지 않음 |

내비 기록, Strava·komoot 같은 활동 기록, 지자체 스탬프 앱, 제조사 커넥티드 앱과의 차별점 가설은 차량 상태·기본 내비·정차 후 보상의 연결이다. 경쟁 앱에 특정 기능이 없다고 단정하지 않는다. 최신 공식 기능 비교와 대체 행동은 [사용자 검증 계획](research/VALIDATION_PLAN.md)으로 확인한다.

## 4. 데이터 처리와 연결

기본 모드는 기록을 차량에 보관한다. 지도 범위 요청으로 OpenFreeMap에 지역과 네트워크 정보가 전달될 수 있지만 경로 배열은 지도 제공자에게 보내지 않는다.

선택적 연결은 동의한 기록의 전체 경로·시각·목적지·거리·시간 등을 자체 서버에 저장한다. 연결 전 기록은 별도 선택해야 전송된다. 연결별 저장·대기열을 분리하고 연결 해제는 서버 삭제와 구분한다. [데이터 안내](PRIVACY.md)를 따른다.

## 5. 사업과 반복 이용

지자체·관광지·렌터카에 콘텐츠·운영·통계의 가치를 제안한다. 계약·유료 시범 실적은 아직 없다. 기록 누적·방문 도장·최근 장소 재출발은 구현됐으나 재방문 효과는 미측정이다. 매출·MAU·4주 재방문율은 가정과 목표다. [사업 계획](BUSINESS_PLAN.md)에 계산 근거와 검증 과제를 적는다.

## 6. 발표 우선순위

목적지 확인→기록 시작→주행 제한→정차 저장→흰 경로 카드·새 스탬프에 집중한다. 효율·구간·세차·모바일 확장은 보조 자료다. 에뮬레이터 재현과 실차 주행을 구분한다.

## 7. 여행 단위로 발전

사용자 승인으로 여러 주행을 하나의 여행으로 묶는 차량 로컬 기능을 추가했다. 이름·대표 장소를 선택하고 기간·거리·기록 시간·휴게·방문을 대표 카드와 타임라인으로 본다. 원본 주행은 유지하며 여행을 해제해도 지우지 않는다. 내 기록은 여행·주행·카드·스탬프로 나눈다.

모빌리티 가치는 출발·주행·휴게·도착의 기록을 사용자가 하나의 여행으로 정리하는 데 있다. 디자인은 기존 흰 경로선·절취선·도장을 여행 엽서로 확장했다. 사업은 지역 콘텐츠 제작·검수·운영을 포함한 시범 제안으로 구체화하되 아직 제휴 성과를 주장하지 않는다.
