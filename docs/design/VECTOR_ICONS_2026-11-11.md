# DRIVELOG 전용 벡터와 약관 화면

2026-11-11 사용자 요청을 차량 앱에 반영했다.

## 아이콘

`app/src/main/res/drawable/ic_drive_*.xml`의 16개 경로를 직접 작성했다. 외부 아이콘셋이나 비트맵을 사용하지 않는다. 48×48 좌표계, 3.6 두께, 둥근 선 끝·이음을 사용한다. 아이콘 색은 기존 테마와 버튼 상태를 따른다.

- 방향·상태: 왼쪽/오른쪽, 확인, 정보, 오프라인, 새로고침.
- 기록·장소: 위치 핀, 문서, 제본된 기록장, 북마크, 시계, 출발·도착 경로.
- 입력·수집: 검색, 사진, 마이크, 잉크 스탬프.

기존 `CarGlyph` 호출부·텍스트 라벨·터치 영역을 유지하고 `CarIcon`이 벡터 리소스를 표시한다. 방향 화살표는 RTL 자동 미러링을 지원한다.

## 앱 아이콘

[크림 App Store 아이콘](https://apps.apple.com/kr/app/kream-%ED%81%AC%EB%A6%BC/id1490580239)의 검정 바탕·흰 워드마크 구성을 참고했다. DRIVELOG 글자는 직접 만든 응축된 대문자 경로이며 약한 기울기로 주행의 방향감을 표현한다.

전경은 108×108 좌표계의 중앙 안전 영역에 놓고, 배경은 기존 #131417을 사용한다. adaptive icon의 전경·배경·monochrome 연결을 유지했다. 폰트나 원본 크림 그래픽을 포함하지 않는다.

## 약관에 해당하는 개인정보·동의 화면

저장소의 실제 고지 화면인 `PrivacyScreen`과 `LinkConsentScreen`을 개선했다. 별도 법률 조항을 새로 작성한 것은 아니다.

긴 문단을 문장 단위 항목으로 나누고, 번호·소제목·구분선으로 구획했다. 최대 본문 폭 840 디자인 단위, 최소 18sp, 줄 간격 1.6배, 테마 본문색을 적용했다. 본문과 연락처·주소는 줄 수로 잘라내지 않는다. 원문 고지와 기존 동의·거부·과거 기록 전송 선택은 보존한다.

## 검증

- `:app:assembleDebug :app:testDebugUnitTest --offline` 성공, 기존 테스트 94개.
- 벡터 리소스 AAPT 처리 및 Kotlin 컴파일 통과.
- 연락처 표시 최종 수정 후 `:app:assembleDebug :app:lintDebug --offline`도 성공.
- 실제 전경 경로로 렌더링한 워드마크 미리보기에서 글자·정렬 확인.
