## 4. 행동 규칙 (반드시 지킨다)
- **읽기 전용이다.** 파일을 고치거나 만들지 말고, 커밋·push도 하지 마라.
- **에뮬레이터를 건드리지 마라.** `adb install`·uninstall, 앱 데이터 삭제, 기록·복구 화면 조작, 위치·기어 주입, `scripts/demo-drive.ps1` 실행, 호스트 마이크 켜기(`adb emu avd hostmicon`)를 하지 마라. 사용자가 에뮬레이터를 쓰고 있다. 화면 캡처나 `adb shell dumpsys`처럼 읽기만 하는 조회는 해도 된다.
- 빌드와 테스트는 해도 된다: `./gradlew :app:testDebugUnitTest`, `./gradlew :app:lintDebug`, `server`의 `./gradlew test`. 결과는 그대로 보고하고, 실패하면 출력도 함께 붙여라. release 서명 빌드(`packageSubmissionApk`)는 키가 없을 수 있으니, 실행했다면 결과만 적어라.
- **객관적으로 평가하라.** 격려하려고 점수를 올리지도, 근거 없이 깎지도 마라. 실제 공모전 상위 10팀 수준과 비교하라.
- 모든 판단에 근거를 붙여라. 코드는 `파일경로:줄번호`, 문서는 파일명과 절 제목으로 적는다.

## 5. 공통 점검표 (심사위원 모두 확인하고 결과를 표로 낸다)

### A. 제출 요건
- `apk/` 폴더와 파일명이 `팀명_DRIVELOG_release.apk` 형식인가. git에 들어 있는가, 아니면 별도 제출인가. README의 `<팀명>` 자리표시자가 아직 남아 있는가.
- README 필수 항목 4개가 모두 있는가.
- `keystore.properties`나 서명 키, `server/.env` 같은 비밀 값이 git 이력에 들어간 적이 있는가(`git log --all -- '*.keystore' keystore.properties server/.env`, `.gitignore`).
- release 빌드가 정말 debuggable이 아닌가. 진단·커뮤니티·휴대폰 미리보기가 `BuildConfig.DEBUG`로 막혀 있는가. QR과 휴대폰 연결 버튼이 기본 빌드에서 숨겨지는가.

### B. CLAUDE.md 핵심 규칙이 실제 코드에서 지켜지는가 (규칙마다 통과/위반/미확인과 근거)
- 기어·속도 같은 표준 데이터는 AAOS Car API로, 특화 기능과 내비는 Pleos SDK로 읽는가.
- 경로 안내는 기본 내비에 맡기고, 요청은 사용자가 눌렀을 때만 보내는가.
- 내비의 추천 경로선을 그리지 않고, 내비가 준 거리·시간을 보이며 `OverviewRoute`로 내비 화면을 여는가.
- 주행 중(주행 제한 활성 또는 기어가 P가 아님)에는 기록 화면이나 잠금 안내만 렌더링하는가. 기록 화면에는 장소, 분 단위 시간, 거리만 보이는가.
- 애니메이션은 정차 중에만 켜지는가. 새 효과마다 `LocalMotionEnabled`를 확인하는가.
- 시뮬레이션 값에 표시가 붙는가. 예: 홈의 이번 달 수치에 시뮬레이션 기록이 섞일 때 표시되는가, 효율(전비/연비)이 시뮬레이션 기록에서는 나오지 않는가.
- 지도는 정차 중에만 받는가. 경로 좌표를 외부 지도 서비스로 보내지 않는가.
- 음성 인식 결과는 검색창에만 들어가고, 내비 검색은 `찾기`를 눌렀을 때만 열리는가.
- 커뮤니티 공개 코스는 경로 앞뒤 500m를 자르고 출발지를 동네 단위로만 보이는가.
- 최상단 Back이 `moveTaskToBack`인가. 시스템 바·독·운전 뷰를 앱이 그리지 않는가.
- 색상과 컴포넌트가 Pleos 토큰을 따르는가. 카드 경로는 속도별 색 없이 흰 선인가.

### C. 11-06 평가 지적 사항 재확인 (항목별로 해결/부분/미해결과 근거)
release APK와 서명 / 문제 정의와 사업 문서 / 화면 자료와 시연 영상 / QR 호스팅(이제 `web/`이 빠져 휴대폰 앱으로 대체된 것이 맞는지) / 장소 사진의 출처와 권한 / DO 선언과 앱 카테고리 / release에서 진단 화면이 열리던 문제(`CarApp.kt`) / 위치 지원 여부 재판정 / outbox에 쌓이는 경로 / 기록 중 상단 '뒤로'의 의미 / 내비에서 앱으로 돌아오는 안내

### D. 문서와 코드의 일치
- `PRODUCT_BRIEF.md`, `BUSINESS_PLAN.md`, README에 이미 뺀 QR 웹, "서버 없는 전달", "경로 비수집" 설명이 남아 있는가. 휴대폰 연결 모드에서는 경로가 서버로 간다는 점을 개인정보 설명에서 모드별로 나눠 적었는가.
- `PLEOS_DESIGN_PRINCIPLES.md`의 홈 규칙("글만 있는 한 열, 지도·아이콘·구분선 없음")과 실제 `HomeScreen.kt`가 맞는가. 최근 드라이브 행의 지도 썸네일, `바로 출발` 목록의 구분선을 확인하라.
