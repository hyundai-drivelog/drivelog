# Pleos 앱 설계 원칙 (DRIVELOG 적용판)

[앱 기획·설계 가이드](https://document.pleos.ai/docs/pleos-only/vehicle-app-planning-guide/intro)와 [UI 디자인 가이드](https://document.pleos.ai/docs/connect/guide/docs-design/Introduction/intro)를 2026-11-03에 읽고 요약했다. 원문의 전재가 아니며, 정책은 차종·플랫폼 버전에 따라 바뀔 수 있으니 심사 전에 원문을 다시 확인한다.

설계를 바꾸기 전에 이 문서를 먼저 확인한다. API 연동 방법은 [PLEOS_API_INTEGRATION.md](PLEOS_API_INTEGRATION.md)에 있다.

## 1. 결정 기준

1. **운전자 주의 분산 최소화가 기능보다 앞선다.** 충돌하면 기능을 줄인다.
2. **직접 구현하기 전에 플랫폼 기능부터 찾는다.** 표준 데이터는 AAOS, 특화 기능은 Pleos SDK, 경로 안내는 기본 내비다.
3. **지원 여부는 런타임에 확인한다.** 차종 이름으로 분기하지 않는다.
4. **PRD와 가이드가 충돌하면 가이드를 따르고 PRD 변경을 기록한다.**

## 2. 주행 안전

| 원칙 | DRIVELOG 적용 |
|---|---|
| `CarUxRestrictions`로 제한 상태 확인, 제한 기능은 축소·비활성화 | 제한 활성 또는 기어가 P가 아니면 `기록 중` 또는 `주행 중` 안내 화면만 렌더링 (`CarApp.kt`) |
| 1~2초 안에 파악 가능한 핵심 정보만 표시 | 기록 중 화면은 장소, 경과 시간, 거리, 상태 문구만 표시 |
| 동영상, 애니메이션, 텍스트 자동 스크롤 금지. 장식 요소 지양 | 애니메이션 없음. 주행 중 움직이는 요소는 초 단위 숫자뿐 |
| 최소 조작, 깊은 메뉴와 드롭다운 지양, 잦은 자동 전환 지양 | 탭 2번 이내 기록 시작. 자동 전환은 P 진입 시 종료 확인 화면 하나뿐 |
| 키보드보다 프리셋, 즐겨찾기, 최근 항목, 음성 우선 | **목표 장소는 내비 즐겨찾기·최근 목적지에서 선택, 목표 이름은 프리셋** |
| 음성·물리 버튼 연계 | 기록 시작, 도착, 정차 시 TTS 안내 |
| 게임, 인터넷 서핑, 피트니스 유도 금지 | 거리 경쟁, 연속 운전 달성 없음 |

### 수치 기준

| 항목 | 기준 |
|---|---|
| 입력 후 시스템 응답 | 0.25초 이내, 지연되면 응답 중임을 표시 |
| 대비 | 아이콘·텍스트·이미지 4.5:1 이상 |
| 주요 텍스트 높이 / 보조 텍스트 높이 | 5mm 이상 / 3mm 이상 |
| 문단 | 3줄 이하, 한 줄 80자 이하 |
| CPU (비내비 앱) | 주행 중 5% 미만, 정차 중 25% 이하 |
| RAM | 400MB 이하 |

터치 영역 최소 수치는 UI 디자인 가이드의 디스플레이 레이아웃·컴포넌트 문서를 따른다. 코드에는 64dp 하한을 두었고, 공식 수치와 대조가 필요하다.

## 3. 주행 규제 정책

- DO 미선언 앱은 **주차 중에만 사용 가능**하다. 기록 중 화면(목업 03, 04, 12)을 유지하려면 DO 선언이 필요하다.
- DO 선언 앱은 `CarUxRestrictions`와 `ActiveRestrictions`를 확인해 직접 제한을 적용해야 한다.
- 규제는 속도, 기어, 브레이크 신호와 지역 규정으로 결정된다. **지역별 허용 여부를 앱이 추측하지 말고 플랫폼이 내려주는 값을 따른다.**
- 공개 표는 북미, 유럽, 그외 지역만 구분하며 **한국이 명시되어 있지 않다.**
- 플래그: NO_DIALPAD(1), NO_FILTERING(2), LIMIT_STRING_LENGTH(4), NO_KEYBOARD(8), NO_VIDEO(16), LIMIT_CONTENT(32), NO_SETUP(64)

## 4. 앱 카테고리

- 모든 앱은 개발·등록 시 카테고리를 선언한다. 선언과 실제 기능이 다르면 즉시 반려된다.
- 주행 중 예외가 예시된 카테고리는 Music/Audio, Maps/Navigation, Mobility Services뿐이다.
- DRIVELOG는 경로 안내를 하지 않으므로 **`APP_MAPS`를 선언하지 않는다.** 경로 안내는 기본 내비에 위임한다.
- **미결:** Lifestyle과 Mobility Services 중 어느 쪽이며, 기록 화면의 주행 중 유지가 허용되는지 `partnership@pleos.ai`에 확인이 필요하다.

## 5. 앱 구조와 화면

- 운전 뷰(Driving view)와 시스템 바는 플랫폼이 소유한다. **목업의 상태바·독·공조 바는 앱이 그리지 않는다.**
- 앱 영역은 window 1개(portrait) 또는 2개(landscape)이며, 사용자가 크기와 위치를 바꿀 수 있다.
- **portrait에 핵심 기능, landscape에 부가 정보**를 둔다. 두 형태를 모두 설계한다.
- 레이아웃은 인치가 아니라 실제 window 크기로 결정한다 (`CarLayout.kt`).
  - 공개 해상도는 17인치 2560×1440뿐이고, 12.9·14.6인치 해상도는 공개 자료에서 찾지 못했다.
  - 공식 [디스플레이 레이아웃](https://document.pleos.ai/docs/connect/guide/docs-design/getting-started/layout) 문서와 대조가 필요하다.
- 백그라운드에서는 화면 갱신, 폴링, 타이머를 줄이고, 프로세스가 죽어도 진행 상태를 복원한다.
  - 기록 좌표와 전송 대기열은 파일에 저장하며, 복구 화면(목업 10)을 제공한다.
  - 백그라운드에서는 보낼 내용이 있을 때만 동기화한다.
- 초기화는 최소로 하고 나머지는 지연 로딩한다.

## 6. CCP와 Back 키

- 최상단 화면의 Back은 **앱을 숨긴다** (`moveTaskToBack(true)`). `finish()` 금지. 미구현 시 심사 반려 대상이다.
- 하위 화면에서는 이전 화면으로 돌아간다. 기록은 숨겨진 뒤에도 계속된다.
- 사용자 설치 앱의 CCP 지원은 선택이지만, 미지원이면 `com.hmg.rotary.ROTARY_SUPPORTED=false`를 선언하고 터치만으로 모든 조작이 끝나야 한다. 현재는 미지원으로 선언했다.

## 7. 내비 관련 정책

- 단일 경로 원칙: Active Route인 내비 앱은 하나뿐이다. DRIVELOG는 자체 경로 안내, TBT, 음성 길안내를 하지 않는다.
- 경로 요청은 **사용자가 명시적으로 눌렀을 때만** 보낸다. 기록 시작이 안내를 시작하지 않는다.
- 주행 중 광고, 영상·게임 요소, 전체 화면 팝업은 금지(즉시 반려 항목)이다.

## 8. 네트워크와 하드웨어

- 앱은 차량 장치에 직접 접근하지 않고 플랫폼 API만 쓴다.
- 비필수 모바일 전용 기능은 제거하거나 지원 여부 확인 후 동작하게 한다.
- 캐싱, 재시도와 타임아웃, 오프라인 안내 UI를 둔다 (목업 09).

## 9. 보안과 개인정보

- 운전자가 바뀔 때 연결 해제와 계정 전환이 쉬워야 한다 → 홈 화면의 `연결 해제`.
- 토큰은 Keystore 같은 안전한 저장소에 보관한다 → `TokenVault`.
- 위치, 음성, 계정 정보는 왜 필요한지 먼저 밝히고, 필요 없는 PII는 저장하지 않으며, 로그에서 마스킹한다.
- 불필요한 권한 요청은 반려 사유다. 승인 범위 밖 퍼미션을 선언하면 심사를 통과할 수 없다.
- 운전 행동 데이터를 마케팅에 쓰지 않는다.

## 10. PRD에서 바뀐 결정

| PRD | 변경 | 이유 |
|---|---|---|
| F01: 모바일 웹에서 지도 검색으로 목표 생성 | **차량에서 정차 중 내비 즐겨찾기·최근 목적지로 생성** | 프리셋·최근 항목 우선 원칙, 내비 API 연동. 좌표와 POI가 내비와 일치해 경로 요청이 정확해짐 |
| F01: 장소 변경은 모바일 웹 | 차량에서 변경, 웹은 이름 변경·삭제만 | 동일 |
| 휴대폰 연결이 먼저 | 첫 기록 후 연결 가능 (목업 07의 순서) | 서버 없이도 차량 기록 흐름 전체가 동작 |
| 서버의 장소 검색 | 삭제 | 내비가 장소의 출처. 외부 검색 서비스로 위치 질의를 보내지 않음 |

## 11. 미결 사항

1. 앱 카테고리와 주행 중 화면 유지 허용 범위, 한국 규제 구분 → `partnership@pleos.ai`
2. 플래그 기준 세부 UX 사양서는 비공개
3. 터치 영역, 12.9·14.6인치 해상도 → UI 디자인 가이드 하위 문서와 대조
4. Sync·ADAS: SDK 사용 가이드 목록에 없음 (Vehicle, NaviHelper, TTS, STT, FusedLocation 5종) → PLEOS_API_INTEGRATION.md 참고
