# 사용자·구매 검증 계획

상태: 계획. 실제 면담·계약·사용자 실험을 수행한 결과가 아니다.

## 사용자 5명 문제 인터뷰

대상은 월 1~2회 여행·근교 드라이브를 하는 운전자다. 동승자 경험도 함께 묻는다. 녹음·개인정보는 동의한 범위에서만 보관한다.

| 질문 | 확인하려는 것 |
|---|---|
| 최근 드라이브에서 무엇을 남겼고 무엇이 아쉬웠나요? | 유도 질문 없이 실제 문제 확인 |
| 지금 쓰는 내비·사진·기록 방식은 무엇인가요? | 대체 행동과 경쟁 서비스 |
| 기록을 시작하지 못했던 구체적인 순간이 있나요? | 빈도·심각도·시작 망각 |
| 목적지→기록→정차 카드 흐름을 혼자 수행해 주세요 | 시작 성공률·복귀 혼란·조작 수 |
| 다음 여행에도 쓸 이유와 쓰지 않을 이유는? | 반복 가치 가설 |
| 기록이 서버로 가는 선택적 연결을 원하나요? | 동의 이해·기본 기능과 확장 구분 |

기록 양식: 익명 참가자 ID / 날짜 / 대상 적합성 / 실제 경험의 원문 요약 / 기존 도구 / 과제 결과 / 혼란 지점 / 재사용 이유 / 반대 증거. 빈 양식을 실적처럼 작성하지 않는다.

## 지표 정의

| 지표 | 정의 | 현재 상태 |
|---|---|---|
| 기록 시작 성공률 | 목적지 선택 과제 참가자 중 도움 없이 기록 시작 성공 비율 | 미측정 |
| 내비 복귀 이탈률 | 내비로 전환한 참가자 중 기록 시작에 도달하지 못한 비율 | 미측정 |
| 저장 완료율 | 시작된 기록 중 의도한 저장을 완료한 비율 | 미측정 |
| 4주 재방문율 | 첫 사용 코호트 중 4주째 다시 사용한 고유 사용자 비율 | 목표 25~35%, 관찰 전 |
| 월 고유 사용자 | 반복 대여·동일인 중복 제거 후 월 사용한 사람 수 | 익명 측정·동의 설계 필요 |
| 월 이용 기회 | 렌터카 대여 횟수 등 잠재 세션 수 | MAU와 구분 |

동의 없는 원격 분석 SDK·경로 수집을 새로 추가하지 않는다. 5명 인터뷰는 통계적 시장 검증이나 4주 유지율의 증거가 아니다.

## 첫 유료고객 면담

지자체 관광 담당자 또는 렌터카 구매 담당자를 대상으로 구매 주체·예산 항목·발주 시점·기존 운영비·필요 성과를 확인한다. 지역 스탬프 연 3천만~5천만원과 차량 월 1천원은 가정으로 제시하고 수용 여부·이유를 기록한다.

시범 제안 구성: 한 지역·명소 범위 / 대상 차량 / 운영 기간 / 지원 책임 / 콘텐츠 사용권 / 동의·데이터 최소화 / 성공 지표 / 시범 비용 / 다음 계약 판단 기준. 상대 회신·계약 전에는 제휴 확정이라고 쓰지 않는다.

## 경쟁 비교

티맵·카카오내비, Strava·komoot, 지역 스탬프 앱, 제조사 커넥티드 앱을 비교한다. 공식 기능 URL·확인일·기록 시작 방식·차량 신호·결과물·데이터 처리·실제 사용자 대체 행동을 기록한다. 최신 자료 확인 전에는 기능 부재나 우위를 확정하지 않는다.
