# DRIVELOG 개인정보 및 데이터 처리 안내

적용 코드 기준: 2026-11-10 평가 후 수정. 앱 홈의 **개인정보와 데이터 사용**에서 오프라인으로 열람할 수 있다.

이 문서는 구현에 따른 안내다. 정식 배포 전 운영자 실명·문의 창구·공개 URL·지역별 필요 신고와 보유·삭제 절차를 확정해야 한다. 확정되지 않은 운영·법적 검토를 완료로 표시하지 않는다. 운영자 정보는 사용자 답변 대기 중이다.

## 기본 차량 모드

| 항목 | 목적 | 저장·전송 | 보유·삭제 |
|---|---|---|---|
| 목적지 이름·좌표, 주행 위치·시각·거리·시간 | 기록·카드·방문 스탬프 | 차량 앱 내부 파일 | 기록 삭제 또는 앱 데이터 삭제까지 |
| 선택한 휴게, 측정 가능한 에너지 정보 | 휴게·전비·연비 표시 | 기록과 함께 차량 저장 | 해당 기록과 함께 삭제 |
| 사용자가 작성한 여행 이름·포함 주행 ID·대표 주행 | 여러 주행을 한 여행으로 열람 | 차량의 현재 연결별 로컬 파일. 이번 구현은 서버에 여행 메타데이터 미전송 | 여행 묶음 해제·앱 데이터 삭제까지. 묶음 해제는 원본 주행을 삭제하지 않음 |
| 최근·저장한 장소 | 재출발 | 차량 저장 | 앱 데이터 삭제까지. 저장한 장소는 저장 취소 가능 |
| 지도 요청 지역·네트워크 주소 | 지도 조각 수신 | OpenFreeMap에 요청. 전체 경로 배열은 미전송 | 차량 지도 캐시는 기록 삭제와 앱 데이터 삭제로 정리. 제공자 보유 정책은 제공자 안내 확인 |
| 음성 입력 | 검색창에 검색어 채움 | 사용자가 누를 때 Pleos 기기 내 처리. 앱은 녹음 파일 미보관 | 앱의 검색 상태만 유지 |

첫 데이터 사용 동의를 거부하면 장소 검색·위치 수집·새 기록 흐름을 시작하지 않는다. 위치 권한 거부 시 기록을 시작할 수 없고 에너지 권한 거부 시 기록은 가능하지만 효율 표시가 빠진다. 기본 내비가 처리하는 검색·안내의 데이터 정책은 내비 제공자 정책을 따른다.

## 선택적 Android 앱 연결

- 기본 제출 빌드는 연결 기능이 꺼져 있다. 연결 기능을 포함한 빌드에서도 서버 전송 동의 버튼을 누르기 전에는 연결 코드를 만들지 않는다.
- 목적지·전체 경로 좌표와 시각·거리·시간·휴게·에너지 정보·연결 인증 정보를 설정된 자체 서버로 전달해 휴대폰 기록·카드·스탬프 조회에 사용한다. 운전 데이터 판매·광고 용도로 사용하지 않는다.
- 연결 전 차량 기록 전송은 **기본 미선택**이다. 본인 기록인지 확인하고 별도 선택한 경우에만 가져온다. 이전 계정의 goal/place 식별자는 가져오지 않는다.
- 원본 토큰은 Android Keystore로 암호화한다. 기록 JSON과 파일 경로에는 원본 토큰을 쓰지 않는다. 연결별 토큰 해시 디렉터리에 기록·대기열을 분리한다. 토큰별 분리이므로 같은 계정 재연결도 새 토큰이면 새 로컬 공간이다.
- 연결 해제는 자동 전송을 중지하고 로컬 기본 공간으로 돌아간다. 이미 시작한 HTTP 요청은 이전 연결의 토큰으로만 끝나며 새 연결 공간에 응답을 적용하지 않는다. 이전 연결 기록은 별도 파일에 보존하고 새 연결에 자동 복사하지 않는다.
- 연결 전 로컬 기록은 연결 해제 후 다시 볼 수 있다. 해제된 연결의 별도 파일과 서버 사본은 자동 삭제하지 않는다. 앱 삭제로 차량 사본을 지울 수 있으나 서버 사본은 별도 삭제해야 한다.
- 서버 사본은 삭제 요청까지 보관한다. 연결된 내 기록의 삭제는 서버에 큐잉되며 네트워크 연결 후 반영된다. 운영자의 서버 전체 삭제·열람 요청 창구와 백업 파기 절차는 정식 배포 전에 확정해야 한다.
- 기존 설치의 동의 없는 레거시 연결은 업데이트 후 자동 전송을 재개하지 않는다. 기존 파일을 보존하고 연결 전송 동의를 다시 받는다.

## 정식 연결 release의 필수 설정

- `releaseApiBaseUrl`: 접근 가능한 HTTPS 자체 서버.
- `privacyPolicyUrl`: 공개 개인정보처리방침 HTTPS 주소.
- `privacyContact`: 실제 운영자·문의 연락처.

연결 release는 이 설정이 빠지면 빌드가 실패한다. 값의 존재 검사는 법적 적합성·URL 접근성·운영자 확인을 대신하지 않는다. 차량 기본 release는 서버 연결이 없으므로 서버 설정을 요구하지 않는다. 기본 앱의 최종 마켓 등록정보·운영자 안내도 제출 전에 확인한다.
