# 벡터 아이콘·개인정보 화면 에뮬레이터 검증

2026-11-11 사용자 요청으로 실제 설치·조작·화면 캡처를 수행했다. 실차 검증은 아니다.

## 환경과 데이터 보존

- 기존 AVD DRIVELOG_Pleos, emulator-5554, Android 사용자 10, 2560×1440.
- 기존 연결 기능을 유지하도록 `:app:assembleDebug -PphoneLinkEnabled=true --offline`로 빌드했다.
- 두 차례 업데이트 설치 각각 직전에 `files/recording`이 비어 있음을 확인했다. `adb install -r -t --user 10`을 사용했으며 앱 삭제·데이터 초기화는 하지 않았다.
- 최초 설치 전 앱 파일·설정을 Git 제외 `.local-qa/icons-2026-11-11/before-install.tar`에 비공개 백업했다.
- 검증 전후 주행 3건·여행 1개·6.9204776281268305km 유지. 주행 객체·여행 객체 및 전체 journey-store.json 내용을 JSON으로 비교한 결과 모두 동일하다. 최종 진행 기록도 없다.
- 새 주행·위치·기어를 주입하지 않았다. 서버 연결 동의·기록 전송은 실행하지 않았다.

| 화면·조작 | 결과 |
|---|---|

| 홈 라이트·다크 | 기록장·스탬프·경로·화살표 벡터 정상 표시 및 테마별 색 전환 |
| 목적지 화면 | 검색·마이크·위치·최근 검색 시계·화살표 정상 표시. 음성 입력이나 목적지 선택은 실행하지 않음 |
| 개인정보 넓은 창 | 제목·요약·번호·구분선·본문 표시, 6개 절과 하단 돌아가기 버튼까지 스크롤 가능 |

| 다크 개인정보 | 흰 본문과 구분선 표시, 하단 출처·돌아가기 버튼까지 접근 가능 |

| 환경 복원 | 시스템 night mode를 원래 no로, 창을 원래 넓은 배치로 돌리고 앱 홈에 복귀 |

창 크기는 플랫폼의 분할 핸들을 드래그해 바꿨다. `wm size`로 해상도를 바꾸지 않았다. 넓은 앱 영역은 [853,90][2535,1300]이다.

## 발견 후 수정

첫 개인정보 항목의 마지막 ‘요.’가 다음 줄에 홀로 표시되는 것을 실제 화면에서 발견했다. `PolicyParagraph`에 기존 `keepWordsTogether`를 적용해 한글 단어 단위 줄바꿈으로 수정했다. 확장 debug APK를 다시 빌드·설치한 뒤 넓은 창과 2분할 창에서 ‘사용해요.’가 단어 전체로 넘어가는 것을 재확인했다.

## 검증 범위의 한계

대표 화면에서 사용하는 아이콘을 확인했으며 16개 모든 아이콘의 모든 상태를 개별 실행하지는 않았다. TalkBack 실제 낭독, 최초 데이터 동의의 승인 동작, 연락처·공개 처리방침 URL이 채워진 빌드, 실차·실제 휴대폰은 이번에 검증하지 않았다. 개인정보 화면은 현재 빌드에서 연락처와 URL 설정이 비어 있어 해당 항목이 표시되지 않는다.
