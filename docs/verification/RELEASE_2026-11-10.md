# 제출용 release APK 실행 검증 (2026-11-10)

심사위원이 실행할 release APK를 Pleos 에뮬레이터에서 처음부터 끝까지 돌린 기록이다. 그전까지의 검증은 모두 debug 빌드였다.

## 빌드

- 명령: `./gradlew :app:packageSubmissionApk -PsubmissionTeam=DRIVELOG`
- 결과: `apk/DRIVELOG_DRIVELOG_release.apk` (약 70MB)
- 서명: `apksigner verify` 통과, 인증서 SHA-256 `f70564b7…` (release 키와 일치). debuggable 아님.
- `cardWebUrl` 없이 빌드했다. 그래서 QR(휴대폰으로 보내기)과 코스 추천 QR은 나오지 않는다. 카드 페이지를 호스팅한 뒤 `-PcardWebUrl=https://…/`로 다시 빌드해야 한다.

## 환경

- AVD `DRIVELOG_Pleos` (`system-images/android-34/pleos_car_emulator/x86_64`), 사용자 10
- debug 앱을 지우고(`adb uninstall`) release를 새로 설치했다. 심사위원과 같은 첫 실행 상태다.
- 위치와 기어는 `scripts/demo-drive.ps1`로 넣었다(`-Prepare` 후 기록 시작, 다시 실행).

## 결과

| 단계 | 결과 |
|---|---|
| 첫 실행 | 앱 소개 화면이 뜬다. `건너뛰기`로 홈 |
| 홈 | 제목, `드라이브 시작`, 이번 달 수치 3칸, `내 기록`. debug 전용 `추천 코스`는 없다 |
| 장소 검색 | 최근 검색이 Pleos 내비에서 온다(송정 해수욕장 등) |
| 장소 확인 → `길 안내 및 기록 시작` | 권한 창 3개(위치, 자동차 정보, 이름 없는 Pleos 권한) 허용 후 내비가 경로를 계산하고 앞으로 나온다 |
| 기록 화면 | 장소, `1분 미만`, `0.0 km 추정 거리`, `기록 종료`, `내비 화면 보기` |
| 주행 재현(D → 5.6km → P) | 종료 확인에 5.5km, 4분, 실제 지도 위 경로, `송정 해수욕장까지 4.2 km` |
| `저장하고 마치기` | 카드 `송정에 남긴 하루`, 경로 그리기, 해운대 해수욕장 새 스탬프, 지도 출처 표기 |
| `기록 보기` | 기록 시간, 출발–도착 시각, 내비 추천 경로, 새 스탬프, 1km 구간 기록. 제휴 혜택 목업 없음 |
| 홈 다시 보기 | 이번 달 1회·5.5km·스탬프 1, 최근 드라이브 행(지도 썸네일) |

## 확인한 문제와 남은 것

- 세 번째 권한 창의 문구가 "알 수 없는 작업 실행"으로 나온다. 앱이 요청하는 Pleos 권한(`pleos.car.permission.*`) 중 하나에 시스템 이름표가 없어서다. 앱에서 바꿀 수 없으므로 README의 심사 안내에 미리 적어 두는 것이 좋다.
- 내비 추천 경로(387km, 약 4시간 10분)는 에뮬레이터 내비가 자기 위치(서울)에서 계산한 값이다. 기존에 알려진 차이다.
- QR 장면은 `cardWebUrl` 호스팅 뒤 다시 확인해야 한다.
- 시험 기록은 확인 후 앱 데이터를 지워 정리했다.
