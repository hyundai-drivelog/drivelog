# 전국 스탬프 확장 검증

2026-11-08. [명소·좌표 출처와 유지보수](../STAMP_CATALOG.md).

- 기존 부산 8곳 유지, 다른 16개 지역에 각 3곳 추가: 총 17개 여행 지역·56곳.
- SDK 포함 `:app:assembleDebug :app:testDebugUnitTest :app:lintDebug` 최종 성공.
- 단위 테스트 71개 통과, 실패·오류 0개. 모든 명소의 도착 좌표, 겹치는 명소의 최근접 선택, 시뮬레이션·짧은 기록 제외, 1km 밖의 위치 제외를 확인했다.
- Lint 오류 0개, 경고 68개, 안내 1개. 전체 프로젝트 경고는 남아 있다.
- `node scripts/sync-stamps.mjs --check`: 카탈로그 동기화·중복 ID·국내 좌표 범위·그림 연결 검사 통과.
- `node scripts/check-stamp-cards.mjs`: 확장용 서버 모바일 카드도 56곳 전체의 명소·기울기를 같은 값으로 판정하고 시뮬레이션·짧은 기록·위치 점 부족을 제외함을 확인했다.
- JavaScript 문법 검사, `git diff --check` 통과.
- Pleos 에뮬레이터의 진행 중 기록 폴더가 비어 있음을 설치 직전에 확인하고 debug APK를 업데이트했다. 기존 기록은 보존했고 새 주행은 만들지 않았다.
- 전국 목록 → 서울·제주 명소 화면, 하드웨어 뒤로 가기 → 전국 목록 동작과 새 모티프 렌더링을 확인했다. 화면은 기존 시뮬레이션 기록이 있는 에뮬레이터이며 관광지 방문 실측이 아니다.
